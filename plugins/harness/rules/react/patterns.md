# React (Toss Frontend Fundamentals 기준)

- **가독성**: 복잡한 조건은 이름 붙인 변수로. 함께 실행되지 않는 분기는 컴포넌트로 분리. 중첩 삼항 금지.
- **예측 가능성**: 이름이 같으면 동작도 같게. 숨은 부수효과(로깅, 전역 변경)는 이름이나 호출부에 드러낸다.
- **응집도**: 함께 바뀌는 파일은 같은 폴더에. 도메인 기준으로 묶는다.
- **결합도**: 컴포넌트 하나는 책임 하나. 과한 공통화보다 중복 허용. props drilling은 조합(children)이나 컨텍스트로.
- 훅 의존성 배열을 정확히 채운다. 비결정 값(`Math.random`, `Date.now`)은 렌더 밖으로.
