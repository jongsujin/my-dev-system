# 교훈 기록과 승격

하네스 루프의 마지막 단계. 배운 것이 다음 세션의 시작을 바꾸게 한다.

## 기록 형식

`.harness/lessons.md` (없으면 만든다). 한 줄에 교훈 하나:

```
- [×1] 교훈 내용 — 이유 한 구절 <!-- level:memo updated:YYYY-MM-DD -->
```

- `×N`: 같은 교훈이 나온 횟수
- `level`: `memo`(기억) → `rule`(규칙) → `hook`(기계가 강제)
- 세션 시작 훅이 횟수 순 상위 N개(`context.maxLessons`)를 주입한다. `hook` 단계는 주입하지 않는다.

## 1. 기록

- 무엇을 남길지: **다음 작업의 행동을 바꾸는 것만**. 교정받은 방식, 환경의 함정, 결정의 이유.
- 남기지 않을 것: 끝난 작업 기록, 코드나 git 기록에서 알 수 있는 것, 이번 작업에만 해당하는 것.
- 비슷한 교훈이 이미 있으면 새 줄을 만들지 말고 `×N`을 1 올리고 `updated`를 오늘로 바꾼다.
- 시크릿·개인정보는 쓰지 않는다.

## 2. 승격 점검

기록 후 목록을 훑어 후보를 사용자에게 제안한다 (자동으로 바꾸지 않는다):

| 현재 | 조건 | 제안 |
|---|---|---|
| memo | ×2 이상 | 레포 `AGENTS.md` 또는 `.harness/rules/`에 규칙으로 추가 → `level:rule` |
| rule | ×3 이상, 또는 어기면 사고 | 기계적으로 막을 방법 제안: `.harness.json` `guard.deny`/`guard.ask` 패턴, 린트 규칙, 검증 명령 → `level:hook` |
| 무엇이든 | 90일 넘게 안 쓰임, 또는 틀린 것으로 드러남 | 한 단계 내리거나 삭제 |

여러 레포에 공통인 교훈이면 하네스 원본 저장소의 `rules/`에 올리자고 제안한다.
