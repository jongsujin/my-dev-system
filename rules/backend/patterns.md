# 백엔드 (계약·정합성·실패 처리·경계·관측성)

- **계약**: 입력은 경계에서 스키마로 검증. 에러 응답 형태는 엔드포인트 전체에서 하나로. 목록 API는 페이지네이션과 상한을 둔다. 응답 필드 삭제·의미 변경은 깨지는 변경이다.
- **정합성**: 함께 바뀌어야 하는 쓰기는 한 트랜잭션으로. 재시도될 수 있는 쓰기는 멱등하게(멱등 키·유니크 제약). 외부 발송(알림·결제·웹훅)은 커밋 후에.
- **실패 처리**: 외부 호출(HTTP·DB·큐)에는 모두 타임아웃. 재시도는 멱등한 호출만, 횟수 상한과 백오프를 둔다. 에러는 한곳에서 처리하고 예상된 운영 에러와 버그를 구분한다.
- **경계**: 라우트 핸들러는 얇게(파싱·인가·호출·응답). 비즈니스 로직은 서비스에, DB 접근은 한 계층에.
- **관측성**: 요청 ID가 붙은 구조화 로그. 로그에 시크릿·개인정보 금지. 상태 변경은 누가 무엇을 했는지 남긴다.
- 반복문 안에서 DB·네트워크 호출 금지. 사용자가 정하는 필터 조회에는 인덱스와 limit.
